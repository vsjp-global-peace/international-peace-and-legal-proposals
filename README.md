## Documentary Integrity

Where a document has been digitally signed, formally published, assigned a DOI, or deposited in an external archival repository, that authenticated or archived edition should be treated as the relevant authoritative version for citation purposes.

GitHub copies are provided as an additional public-access and version-history layer and do not replace the authoritative archival record identified for each document.
